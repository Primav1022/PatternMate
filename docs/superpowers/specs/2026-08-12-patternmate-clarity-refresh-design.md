# PatternMate 清晰化与界面减法设计

## 目标

在不改变 PatternMate 业务流程、几何接口和原子级规则的前提下，删除不支持主要任务的视觉与交互设计，让用户更快完成“录入尺寸 → 选择参考 → 组合部件 → 校验纸样 → 导出”的主流程。

本轮不是重新设计产品，也不是继续为旧界面叠加装饰。判断标准是：一个元素如果不能帮助用户做选择、理解系统状态、纠正问题或完成下一步，就删除、合并或降级。

## 设计方向

采用已经确认的 A「暖色工作室」方向：保留 PatternMate 现有棕色与橙色识别，使用中性浅背景、白色工作面板和高对比正文。界面应接近轻量专业制版工具，而不是营销展示页或多层卡片式后台。

## 信息优先级

每一屏只保留四层信息：

1. 当前步骤与当前对象。
2. 用户此刻需要完成的输入或选择。
3. 系统生成、校验或审核结果。
4. 一个明确的下一步主操作。

帮助说明、技术元数据、候选来源和低频工具默认折叠或放入次级区域。

## 删除与合并清单

### 全局框架

- 删除步骤按钮中的装饰性图标，只保留文字、序号和当前状态。
- 删除侧栏标题前无语义的彩色圆点。
- 顶部不同时出现“下载全部数据”和当前页面的下载主按钮；导出集中在流程完成位置。
- 项目名称编辑、语言切换保留，但降低视觉权重。
- 服务连接、分析错误和导出错误合并为统一状态条，同一时间只显示最高优先级消息。
- 保留侧栏拖拽和纸样审核栏拖拽，但缩窄拖拽条并降低常态可见度。

### 首页

- 删除像素装饰背景和无功能的循环服装画廊动画。
- 保留品牌、一个简短价值说明和“开始设计”按钮。
- 语言切换保留为次要操作。

### 人体尺寸

- 删除左侧与右侧重复的长篇测量提示。
- 左侧只保留号型、尺寸字段、记住尺寸和两个必要动作。
- 右侧测量图保留；详细测量方法改为折叠内容，不再默认占据整屏表格。
- 3D 人体只在用户点击生成后出现。

### 服装设计

- 删除设计助手上方的说明卡片，改为输入框内的一句示例。
- 空对话时不渲染聊天记录容器。
- “在线/基础分析模式”只在离线或降级时显示；正常状态不占空间。
- “设计偏好”标题、提示句和标签区合并为一个紧凑区块。
- 袖长等规则提示只在对应条件触发时显示，不常驻。
- 参考图卡片不显示“查看详情”常驻标签；选中后仅显示明确选中状态。

### 编辑搭配与原子部件

- 删除“点击收起/展开”等重复操作文案，使用原生展开符号表达。
- “当前品类”与“参考款部件默认选中”合并为一条简短上下文提示。
- 版片组保留；选项卡只展示缩略图、名称和选中状态。
- 面料与工艺默认折叠，避免与当前主要的部件组合竞争注意力。
- 不再常驻“当前预览已是最新”的禁用按钮；没有待生成变化时隐藏次要生成按钮。
- 页面只保留一个可执行的主按钮，禁用原因显示为按钮附近的一句状态，而不是塞入按钮文字。

### 纸样预览与审核

- 保留 DXF、2D、可用时的 3D 三种视图，不增加新视图。
- 缩短预览标题，删除“完整、人体适配、试样”等重复叠加词。
- 图层管理与显示信息合并为一个“显示”折叠组。
- 自动校验始终可见，优先显示闭合性、版片库存、接缝匹配和人工审核需求。
- 版片清单、纸张尺寸、recipe hash 等技术信息进入“详细信息”折叠区。
- 组合审核先显示每个组件的 `applied / retained_current / review_required / failed`；修改图元数和供体数量进入每项详情。
- 错误信息只说明失败组件、保留状态和恢复动作，不重复解释整套流程。

### 印花

- 保留正反面、模式、素材、必要参数和导出。
- 删除重复的编辑帮助；只在当前模式首次或无选中对象时显示一条上下文提示。
- 无印花状态使用空状态，不再包裹为装饰卡片。

## 视觉系统

- 页面背景：`#f6f4f1`
- 工作面：`#ffffff`
- 主文字：`#292524`
- 次要文字：`#6f6762`
- 边框：`#e5e1dc`
- 品牌棕：`#60332d`
- 操作橙：`#e87924`
- 成功：`#177245`
- 警告：`#a65a15`
- 错误：`#b42318`
- 间距使用 4 / 8 / 12 / 16 / 24 / 32 px；同层级不混用任意间距。
- 正文最小 14 px；非关键元数据可为 12 px；移动端输入字号至少 16 px。
- 按钮和可点击选项最小高度 40 px，关键流程操作为 44 px。
- 阴影只用于模态框和浮层；普通面板依靠边框和空间分组。

## 交互与状态

- 每屏一个主操作；其他操作使用次按钮、文本按钮或折叠内容。
- 选中状态同时使用边框、浅色背景和文字标记，不能只靠颜色。
- 所有键盘可操作元素提供清晰的 `:focus-visible`。
- 加载状态保留上一版有效纸样，显示当前正在处理的组件。
- 某组件迁移失败时显示“保留原部件”，不把整个组合表现为完全失败。
- 动效限制在 150–220 ms，并遵守 `prefers-reduced-motion`。

## 技术边界

- 不修改几何服务、GPU 服务、DXF 数据和规则执行逻辑。
- 不引入 UI 框架和新运行时依赖。
- React 组件只为删除冗余节点、合并状态和改善语义做小范围调整。
- 现有 `styles.css` 保留基础布局，清理 `overrides.css` 中互相覆盖的旧规则；不再新增第三层永久覆盖样式。
- 中文与英文文案同步调整。

## 验收标准

- 首页、尺寸、设计、搭配、纸样审核和印花页面均不存在重复标题、重复说明或两个同权重主按钮。
- 用户在每一屏都能在 3 秒内识别当前任务、系统状态和下一步操作。
- 原子部件状态能明确显示已替换、保留原部件、等待审核和失败。
- 1440、1024、768 和 375 px 宽度无意外横向滚动；DXF 画布本身的平移缩放除外。
- 键盘焦点可见，正文与主要控件满足可读对比度。
- `pnpm test` 与 `pnpm build` 通过，业务请求结构保持不变。
